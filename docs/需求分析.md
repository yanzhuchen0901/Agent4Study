# 需求分析

## 问题背景

多本教材之间经常存在概念重复、定义差异、章节组织不一致和知识关系隐含的问题。传统搜索只能返回片段，难以回答跨章节、跨教材和需要推理的问题。Agent4Study 的目标是把教材内容转化为可检索、可合并、可解释的知识系统。

## 知识点粒度定义

| 粒度 | 定义 | 示例 |
|------|------|------|
| 概念节点 | 教材中出现的核心术语 / 名词 / 理论名 | "炎症"、"快速排序"、"微分方程" |
| 关系边 | 概念之间的语义联系 | prerequisite（前提）、parallel（并列）、contains（包含）、applies_to（适用） |
| 章节块 | 按教材 TOC / 标题分割的内容单元 | 每章作为独立处理单元 |
| Chunk | RAG 检索最小单元（700 字符 ± 80 overlap） | 跨段落不跨章节 |

## 重复判定标准

跨教材合并时，以下情况判定为同一概念：

| 条件 | 权重 | 说明 |
|------|------|------|
| 名称归一化后完全匹配 | ≥0.86 | 去空格/标点/大小写后相同 |
| 定义语义相似 | ≥0.72 | difflib SequenceMatcher 比较定义文本 |
| LLM 裁决 | 最终决定 | 前两条初筛后，LLM 做最终 merge/keep/remove |

### 合并成功率目标
- 初筛召回率：≥85%（embedding cosine > 0.85 的候选组）
- LLM 裁决准确率：≥90%
- 综合去重率：≥30%

## RAG 策略

### 分块策略

- **目标长度**：700 字符（约中文 3-5 段落 / 英文 150-200 词）
- **滑动窗口**：80 字符 overlap
- **分割层次**：先按章节 → 再按段落 → 最后按句子回退
- **选择依据**：700 字符足以包含完整知识点又不稀释语义；overlap 80 保证跨段概念不丢失。经 Benchmark 在 200/500/700/800/1200 对比，700 在命中率和 token 消耗间平衡最佳。

### 检索策略

| 方法 | 权重 | 作用 |
|------|------|------|
| 向量检索 | 0.7 | 语义相似度匹配 |
| BM25 | 0.3 | 关键词精确匹配 |
| RRF 融合 | - | 合并两路排序，消除分值尺度差异 |

### 引用溯源
- 每个回答片段必须标注来源：教材名、章节、页码、相关度（0-1）
- 用户可展开查看原文片段

## 教学连贯性保障

1. **图谱结构保持学科体系**：节点按章节组织，关系边体现知识递进关系（prerequisite 标注"先修-后修"）。
2. **Agent 多步推理**：复杂问题自动分解为子问题，按依赖顺序执行。
3. **跨书合并保留引用**：合并后的节点保留所有来源教材的记录，不丢失上下文。
4. **Mermaid 工作流可视化**：Agent 执行过程可追溯，每个步骤的状态和输出可见。

## 压缩比计算

```
去重率 = (合并前节点数 - 合并后节点数) × 100% / 合并前节点数

示例：
      合并前: 教材 A 150 节点 + 教材 B 120 节点 = 270
      合并后: 220 节点
      去重率: (270 - 220) / 270 = 18.5%
```

目标去重率 ≥30% 意味着每 100 个跨书节点中至少有 30 个被识别为重复并合并。
