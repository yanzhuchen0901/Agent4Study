## 导入方式

执行以下脚本将数据集同步到项目本地教材目录：

```powershell
.\scripts\import_testbooks.ps1
```

默认导入目标为 `data/textbooks/`，并生成本地清单 `data/textbooks/testbooks_manifest.json`。

## Git 策略

教材 PDF、导入清单、解析产物、向量块和图谱产物均属于本地运行数据，不进入 Git 仓库。仓库只保留导入脚本和数据集说明，以便复现实验环境。

## 后续使用

导入完成后，可以通过现有上传/解析接口或前端上传页选择 `data/textbooks/` 下的教材文件进行解析。解析完成后，Task3-Task8 的知识图谱、RAG、Agent 和报告流程可直接复用这些解析产物。
