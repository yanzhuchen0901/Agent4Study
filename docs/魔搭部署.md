# 魔搭创空间部署

## 配置文件

仓库根目录的 `ms_deploy.json` 是魔搭 OpenAPI 创建创空间的请求体：

```json
{
  "repo_name": "Agent4Study",
  "owner": "yanzhuchen0901",
  "display_name": "Agent4Study",
  "sdk_type": "docker",
  "hardware": "platform/2v-cpu-16g-mem"
}
```

如果魔搭用户名不是 `yanzhuchen0901`，部署前需要把 `owner` 改为实际魔搭账号或组织名。

## Docker 入口

魔搭 Docker 创空间默认使用仓库根目录 `Dockerfile`。本仓库的默认最终阶段为 `modelscope`：

- 构建 Vue 前端静态文件。
- 安装 FastAPI 后端依赖。
- 将前端 `dist` 复制到后端镜像。
- FastAPI 挂载前端静态文件。
- 使用 `${PORT:-7860}` 启动服务。

## 使用 OpenAPI 部署

先设置魔搭访问令牌：

```powershell
$env:MODELSCOPE_API_TOKEN="your_modelscope_token"
```

执行：

```powershell
.\scripts\deploy_modelscope.ps1
```

该脚本会调用：

- `POST https://modelscope.cn/openapi/v1/studios`
- `POST https://modelscope.cn/openapi/v1/studios/{owner}/{repo_name}/deploy`

## Secret

不要把 LLM Key 写进仓库。部署后在魔搭创空间 Secret 中配置：

| Key | Value |
| --- | --- |
| `LLM_PROVIDER` | `deepseek` |
| `LLM_MODEL` | `deep-seek-v4-flash` |
| `LLM_BASE_URL` | `https://api.deepseek.com` |
| `LLM_API_KEY` | 你的 DeepSeek API Key |

## 数据

教材 PDF 不进入 Git。部署环境可通过前端上传页上传教材，或在魔搭持久化目录中补充 `data/textbooks/`。
